# 正文原生可视化实现与验证记录

基线：`f3eb01464255a1607594ad306b85d7009989e6fd`。分支：`codex/aojit-real`。保持 v1.1.4、iOS 16.0。

## 实现

- 统一 `ze-visualization` 正文协议，指标网格、折线、分组柱状、面积、多序列、饼图、环形图、信息字段与数据表。
- UIKit 原生视图和矢量绘图，避免引入 iOS 17 图表 API 或每卡 WKWebView。正文限制高度，详情复用 UITableView 展示完整数据。
- 图表点选读数、单序列/全部选择、全部/后半段范围；完整数据详情、筛选、数值排序、复制行和 CSV 文本分享。不存在自动远程刷新或隐式取数。
- 普通模型通过统一提示生成载荷；真实数据来自用户或已有工具。数据源引用显示在卡片外；不虚构实时值、缺失数据或历史走势。
- 载荷仍保存在现有消息正文中，沿用 SQLite 和同步机制，无新数据库迁移。流式未闭合 fence 显示稳定状态，不渲染半个 JSON。
- 搜索/复制使用可读字段投影，搜索定位到实际卡片。静态导出使用相同组件并附完整数据文本，保留超出预览的数值和来源。

## 性能、缓存、清理

- 单载荷 256 KiB、最多 12 组件、每回复最多 4 个可视化块、每载荷总共 2000 点、每组件最多 8 序列、48 指标；表格最多 200 行/12 列。
- 解析结果缓存：线程安全 LRU，最多 24 项，估算成本最多 2 MiB；并发清理通过 generation 防止旧解析任务重新写回。
- 渲染器缓存：改为消息 ID + 块 ID，最多 24 项；每渲染器可视化槽最多 4 项、估算成本最多 1 MiB。当前活跃视图仍保留其显示对象，避免清理时引发整屏重绘。
- 内存警告、进入后台、删除会话、设置页手动清理都会释放共享解析与渲染缓存。用户历史数据独立保留。
- 无新增磁盘缓存，无每卡计时器、轮询、自动动画或网络请求；CSV 以文本分享，不产生临时导出文件。
- 缓存容量是上限控制，不是实测内存峰值承诺。实际设备长对话内存与帧率仍须依据运行证据评估。

- `scripts/test-visualization.py`：macOS 编译执行真实模型/缓存测试；独立以 iOS 16.0 simulator target 类型检查生产 UIKit 组件。

## 已知范围

正文和详情中的交互是对已保存数据操作。天气、行情等可使用既有工具取数再呈现，但本次没有新增专用行情订阅、天气账号或自动刷新接口。范围按钮为全部/后半段；尚无自由拖拽缩放。静态分享以全部数据为准，使用者临时选择的过滤状态不作为历史数据写回。

回滚使用本次功能提交的 `git revert <commit>`；基线记录位于本地 `artifacts/tasks/inline-visualization/baseline.json`。不删除会话数据库，不更换分支、不强制推送。
