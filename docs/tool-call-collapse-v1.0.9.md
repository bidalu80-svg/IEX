# v1.0.9 (4)：连续工具调用折叠

## 行为约定

- 入口：设置 → 外观 → 工具调用 → 折叠连续的工具调用，默认开启；关闭后恢复逐条显示。
- 仅同一回复内相邻的两个或更多工具调用成组。单个工具保持原样。
- 文本（包括空文本）、思考、信息提示及最终总结都中断分组，不被隐藏。
- 折叠行显示调用次数、报错次数、累计执行时长（秒）；取消不计入报错。
- 时长为各工具耗时之和；并行工具可能累计超过实际墙钟时间。执行中刷新，完成后读取已记录耗时。
- 展开状态属于首个工具的临时 UI 状态，不改变会话原始 blocks 或持久化格式。
- 轻点分组行展开/折叠；展开后的工具保留原详情入口和长按菜单。

## 长按复制与截图

- 分组行保留复制全部、复制截图；所有工具胶囊转发截图回调，保留复制工具详情和空闲时的重新运行。
- 最终总结原有的选择/复制/截图实现不变。
- 截图时仅临时把 collection view 恢复成原始逐块展示，再调用原滚动截图/拼接实现。
- 原截图主体与基线 `283d4bf` 完全相同（由结构测试固定 SHA256）。
- 无论截图成功还是提前返回，`defer` 都恢复分组、滚动位置和滚动模式；不修改设置或展开状态。

### 真机交互验收（需设备执行，不等同于编译验证）

1. 工具A、工具B、正文、工具C、工具D、最终总结：只出现两个独立分组，总结始终可见。
2. 工具连续追加、成功/失败/取消：计数与秒数更新，完成后秒数停止增长。
3. 分组展开后滚动离屏再返回：展开状态保留；关闭设置恢复所有单条工具。
4. 长按折叠行、展开后的工具、总结：相应复制/复制截图菜单正常，不触发误折叠。
5. 折叠时复制截图：包含用户提问、全部工具和最终总结；结束后分组状态与原阅读位置恢复。
6. 深色模式、大字体、横屏/iPad：总数、报错数、秒数可读，按钮不遮挡内容。
