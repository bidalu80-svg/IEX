# Ze

Ze 是一个面向 iOS 的 AI 工作台，支持多家模型服务商、对话、智能体工具调用、语音、iSH 终端和跨设备同步。

## 产品命名规范

- 应用、界面、文档、示例、资源文件和新功能统一使用产品名 **Ze**。
- 新增用户可见文案必须通过本地化资源提供简体中文（`zh-Hans`）翻译。
- 备份文件使用 Ze 专属的 `.zebak` 扩展名；协议字段、数据库键和加密格式标识也使用 Ze 命名。
- 第三方服务商（例如 Kimi、OpenAI、Anthropic）只在描述对应服务或兼容协议时保留其官方名称，不得作为 Ze 的产品名或界面标题。
- 提交前应搜索产品名残留，确认没有把其他应用或旧项目名称带入 Ze 的用户界面、文档或新代码。

## 构建

项目使用 `Ze.xcodeproj`，推送到受保护分支后由 GitHub Actions 的 **Build iOS App** 工作流执行构建、未签名 IPA 打包和产物上传。

本地修改应沿用现有分支和工作流，不创建平行项目或重复的构建流程。
